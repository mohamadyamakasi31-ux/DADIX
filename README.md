# Dadix Web AI — منصة احترافية لبناء المواقع بالذكاء الاصطناعي

منصة متكاملة ومستقلة لإنشاء وتعديل ومعاينة وتنزيل ونشر المواقع الإلكترونية بالذكاء الاصطناعي، مستوحاة من تجربة مطوري الويب الحديثة بهوية خاصة وأنيقة لـ Dadix.

---

## 🌟 أبرز الميزات:

1. **مولّد مواقع حقيقي مدعوم بـ Google Gemini:**
   - يفهم أوصاف المواقع باللغات العربية والإنجليزية والفرنسية.
   - ينشئ ملفات حقيقية (`index.html`, `style.css`, `app.js`, `package.json`, `README.md`).
   - يدعم مشاريع المتاجر الإلكترونية، الشركات، معارض الأعمال الشخصية، المدونات، المطاعم، العقارات، ولوحات التحكم.

2. **المعاينة الحية التفاعلية (Live Preview):**
   - محرك معاينة مباشر يشغل تقنيات HTML5، CSS3، Tailwind CSS، وJavaScript بالكامل.
   - تبديل سهل بين أحجام الأجهزة: **حاسوب (Desktop)**، **لوحي (Tablet)**، و**هاتف (Mobile)**.
   - إعادة تحميل فورية وزر للفتح في المتصفح الخارجي.

3. **محرر الأكواد ومستكشف الملفات:**
   - شجرة ملفات كاملة مع إمكانية إنشاء ملفات جديدة، إعادة تسميتها، وحذفها.
   - محرر أكواد متطور مع أرقام الأسطر وشريط بحث وحفظ فوري.

4. **المحادثة الذكية لتعديل الموقع:**
   - مساعد ذكي داخل المشروع لتعديل التصميم وإضافة الصفحات بناءً على طلب المستخدم (مثال: "غيّر لون الخلفية إلى الأزرق"، "أضف صفحة تواصل").
   - قراءة الملفات الحالية وتطبيق التعديلات الجراحية فقط مع حفظ السجل.

5. **الطرفية التفاعلية (Terminal):**
   - بيئة أوامر تشبه بيئة Node.js وBash تدعم: `npm install`, `npm run dev`, `npm run build`, `ls`, `cat`, `clear`, `help`.

6. **تنزيل المشروع كاملاً بصيغة ZIP:**
   - تصدير كامل لملفات وأصول المشروع بنقرة واحدة كملف ZIP صالح للتشغيل الفوري في أي بيئة استضافة.

7. **النشر الحقيقي على Cloudflare Pages:**
   - تكامل حقيقي مع واجهة برمجة تطبيقات Cloudflare Pages لرفع ونشر المواقع مباشرة مع تزويد المستخدم برابط `pages.dev` الحقيقي.

---

## 💻 التشغيل على Windows 10:

1. تأكد من تثبيت بيئة **Java JDK 17 أو 21**.
2. قم بتشغيل ملف `start.bat` بالنقر المزدوج عليه لبناء حزمة المشروع تلقائياً.
3. سيتم توليد ملف APK المخصص للتشغيل في المسار:
   `app\build\outputs\apk\debug\app-debug.apk`

---

## 🔑 إعداد مفاتيح الخدمة:

1. **Google Gemini API:**
   - ادخل إلى إعدادات المنصة داخل التطبيق أو لوحة أسرار AI Studio.
   - ضع مفتاح `GEMINI_API_KEY` المجاني من [Google AI Studio](https://aistudio.google.com).
   - اختر النموذج المفضل (مثل `gemini-2.5-flash` للسرعة أو `gemini-2.5-pro` للتفكير العميق).

2. **Cloudflare Pages:**
   - من لوحة تحكم Cloudflare، احصل على `Account ID` و `API Token` مع صلاحية (Cloudflare Pages: Edit).
   - أدخل البيانات في قسم إعدادات Cloudflare Pages للنشر بنقرة واحدة.
